About This Exam

AISSEE & UP Sainik School Kya Hai?

All India Sainik Schools Entrance Exam (AISSEE) NTA dwara conduct kiya jaata hai — Class 6th aur 9th mein admission ke liye. Sainik Schools students ko defence services (NDA/CDS) ke liye taiyar karte hain, saath mein UP Sainik School bhi similar pattern follow karta hai.

LBK Cadets Pathshala mein hum academics ke saath physical training, drill, discipline aur SSB-style personality development bhi karwate hain — kyunki Sainik School sirf padhai nahi, character building bhi hai.

Eligibility & Exam Pattern

Kaun Apply Kar Sakta Hai?

📚 Eligibility

Class 5th (Class 6th entry) ya Class 8th (Class 9th entry) mein padhne wale students, age 10-13 / 13-15 years.

📝 Exam Pattern

MCQ based — Maths, Intelligence, Language, GK. Class 6th: 300 marks, Class 9th: 400 marks + interview.

🎯 Selection

Written exam + medical fitness + physical measurement + interview (Class 9th ke liye).

🏫 LBK Batch

Class 3rd se 8th tak — Class 6th aur Class 9th dono entry points ke liye alag batch.

Sainik School Ke Baare Mein Aapke Sawaal

Sainik School ke liye eligibility kya hai?
Class 6th entry ke liye students Class 5th mein, aur Class 9th entry ke liye Class 8th mein padh rahe hone chahiye. Age criteria class ke hisab se alag hoti hai.

Haan, ab Sainik Schools mein girls ke liye bhi seats reserve hoti hain. LBK mein hum sabhi students ko equally taiyar karte hain.
