About This Exam

JNVST Kya Hai?

Jawahar Navodaya Vidyalaya Selection Test (JNVST) Navodaya Vidyalaya Samiti dwara conduct kiya jaata hai — free residential schooling ka mauka rural aur talented students ko dene ke liye. Ye India ke sabse competitive entrance exams mein se ek hai.

LBK Cadets Pathshala mein hum Class 3rd se 9th tak ke students ko JNVST ke Class 6th admission test ke liye 15+ saal se expert taiyari karwate hain — Mental Ability Test (MAT), Arithmetic aur Language sections pe khaas focus ke saath.

🧠

Mental Ability Test (MAT)

50 marks — pattern, series, mirror image, embedded figures ki daily practice.

➗

Arithmetic Test

25 marks — number system, fractions, measurement ki concept-clear taiyari.

📖

Language Test

25 marks — Hindi/regional language comprehension aur grammar.

Eligibility & Exam Pattern

Kaun Apply Kar Sakta Hai?

📚 Eligibility

Class 5th mein padhne wale students (Class 6th admission ke liye), government/recognized school se. Age limit: 9-13 years.

📝 Exam Pattern

100 marks, 100 questions, OMR based, 2 hours duration — MAT (50) + Arithmetic (25) + Language (25).

🎯 Selection

District-wise merit list, rural quota 75%, girls quota 33%, free residential education Class 6-12.

🏫 LBK Batch

Class 3rd se 5th tak ke students ke liye foundation se advanced level tak structured batches.

JNVST Ke Baare Mein Aapke Sawaal

JNVST ke liye age limit kya hai?
Class 6th admission ke liye students ki age 9 se 13 saal ke beech honi chahiye, aur wo Class 5th mein government/recognized school se padh rahe hone chahiye.
JNVST ka exam pattern kya hai?
100 marks, 100 questions, OMR based, 2 ghante ka exam — Mental Ability Test (50), Arithmetic (25) aur Language (25) sections.
LBK mein JNVST batch kab shuru hoti hai?
