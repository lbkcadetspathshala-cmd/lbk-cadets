👨‍🏫 Teacher ke liye instructions

  1. Neeche har course ki current data (jo abhi website ke "Eligibility Checker" tool mein use ho rahi hai) table format mein di gayi hai — ye data internet ki official notifications se liya gaya hai, lekin ise final maanne se pehle verify karna zaroori hai.
  2. Har row ke saamne "Verify" column mein ✅ (sahi hai) ya ❌ (galat hai) mark karein.
  3. Agar ❌ mark karein, to "Correction / Sahi Jaankari" column mein sahi value likh dein.
  4. Bharne ke baad ye sheet (photo/scan/PDF) Kiro ko wapas bhej dein — main is data se website ka Eligibility Checker tool update kar dunga, taaki result 100% accurate ho.
  5. Agar koi field missing lage (jaise koi naya reservation rule, koi naya exam pattern change), use "Additional Notes" column mein likh dein.
